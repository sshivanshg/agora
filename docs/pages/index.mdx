# Agora

**A self-hostable, open-source multi-agent AI debate platform.**

Agora orchestrates AI personas — intellectual archetypes grounded in real traditions — through structured debate formats. A LangGraph state machine drives each debate through phases: framing, opening statements, cross-examination, rebuttals, closing, and synthesis.

Debates stream live to the browser. Users watch, ask follow-up questions, and spin up custom debates on any topic. A fact-checker agent runs asynchronously on every claim.

---

## Design philosophy

- **OSS-first.** Every decision is weighed for contributor ergonomics, self-hostability, and the ability of a stranger to clone and run it in under five minutes.
- **BYOK.** Users supply their own API keys. The project never proxies through a central paid service.
- **Single-user by default.** No login, no signup. Multi-user is a single env-var flip.
- **No Redis.** Postgres only. Boring infra, exciting product.
