# Contributing

See the full guide in [CONTRIBUTING.md](https://github.com/your-org/agora/blob/main/CONTRIBUTING.md).

---

## The fastest contribution: add a persona

1. Copy a file from `packages/personas/specs/`
2. Update the frontmatter and write a 400–600 word system prompt grounded in a real intellectual tradition
3. Open a PR — no code changes needed

## Commit convention

[Conventional Commits](https://www.conventionalcommits.org/): `feat:`, `fix:`, `docs:`, `chore:`, etc.

## Before submitting

```bash
pnpm lint
pnpm typecheck
pnpm test
```

One PR = one logical change. Include screenshots for UI work.
